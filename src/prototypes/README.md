# Prototypes Layer (src/prototypes/)

Code, interfaces, firmware snippets, and documentation for Nexus hardware prototypes: Soilnova (environmental/soil sensing & data oracles), Vista Nova (visualization & dashboards), York Autotype (automation & mechanical systems), Lumia (advanced lighting/display systems).

## Focus Areas
- Sensor/actuator drivers and data pipelines feeding into QCoin incentives or AI decision loops
- Edge computing on low-power hardware integrated with mesh networking
- Visualization tools (Vista Nova) for real-time Nexus status (mesh health, blockchain, swarm activity)
- Automation scripts for York Autotype physical interactions
- Lighting control and effects for Lumia, possibly synced to AI emotional states or network events

## Integration Goals
- Provide real-world grounding and oracles for the digital layers
- Enable tangible demonstrations of the full stack
- Support monitoring dashboards and physical feedback loops
- BOMs, schematics, and build guides stored in assets/

## Next Milestones
- Initial Python interfaces for each prototype
- Dockerized edge deployments
- Data contribution proofs for QCoin rewards
- Visualization dashboard prototype

*Bridging the digital Nexus vision into physical reality with thoughtful engineering and creative hardware play.*
